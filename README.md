# 冷笑话收集站

独角兽吹的泡泡，每个泡泡里藏一个冷笑话或双关。整页一屏、不滚动：泡泡大小按数量自动分配，往上浮、互相挤、绕着独角兽排，大的偏上小的偏下但位置随机；每次刷新重新吹。点一个泡泡：第一下看题，第二下揭谜底，第三下啪地炸掉，下面的泡泡自己浮上来补位。投币是毛绒猫爪举着游戏币塞进投币口的动画（爪子、游戏币、投币口三张图也是 gpt-image-2 画的），计数是假的：随机起步、点一下加一、不保存。所有图片加载完才开始播动画。

收录标准：对话或一句铺垫，最后一句靠谐音或双关翻转（"365 天哪天最长→第 9 天，地久天长"这种）。"什么蛋不能吃"那类脑筋急转弯不收。

## 添一条

只改 `jokes.json`，在数组末尾加一项：

```json
{
  "id": 36,
  "setup": "题面或铺垫，换行用 
",
  "punch": "谜底或最后一句，要再点一下才显示",
  "lang": "zh",
  "country": "CN",
  "topic": "动物",
  "date": "2026-10-29",
  "note": "可选：解释笑点"
}
```

- `id` 递增就行，它决定贴纸颜色、倾斜角、封面样式和撕开动画
- `setup` 以问号结尾时按钮写"揭晓谜底"，否则写"看下一句"
- `lang` 用两位语言码：zh / en / fr，新语言会自动出现在筛选条
- `topic` 自由填，已有：动物 食物 科学 语言 职业 日常 数学；新主题也会自动出现
- `note` 可以不写，只在谜底揭晓后显示

直接在 GitHub 网页上改 `jokes.json` 提交即可，Pages 一两分钟后更新。

## 图

`img/` 里的独角兽、贴纸和六幅场景图（独角兽世界、糖果野餐、中秋夜、万圣节、秋游爬山、火锅聚餐）由 gpt-image-2 生成，提示词和切图脚本在 `_gen/`。每幅场景图整页只用一次，各占一张大卡；要加新场景就往 `index.html` 的 `PICS` 列表里加一行。
